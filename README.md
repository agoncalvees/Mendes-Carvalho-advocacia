# Mendes & Carvalho Advogados

Landing page conceitual de um escritório de advocacia empresarial, desenvolvida com Next.js, React, TypeScript e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run lint
npm run typecheck
npm run build
```

## Deploy

- **Vercel:** importe este repositório; o build estático é gerado pelo comando `npm run build`.
- **Hostinger:** execute `npm run build:hostinger` e envie o conteúdo de `dist` para `public_html`.
- Configure `NEXT_PUBLIC_SITE_URL` com o domínio definitivo quando ele for diferente de `https://mendescarvalho.com.br`.

> Projeto conceitual. Perfis profissionais, registros e endereço apresentados no site são demonstrativos.
